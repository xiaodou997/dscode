# Codex app-server schema 0.146.0

This directory contains the combined stable JSON Schema generated by the stock
`codex-cli 0.146.0` binary:

```bash
codex app-server generate-json-schema --out DIR
```

The command intentionally omits `--experimental`. The split schemas produced by
the same command are not committed because the combined bundle is the canonical
input for DS Code client generation.

The schema is generated from OpenAI Codex. Its upstream Apache-2.0 license and
NOTICE are retained in `UPSTREAM_LICENSE` and `UPSTREAM_NOTICE` in this
directory. These files do not select a license for the rest of DS Code.

When updating this directory, regenerate the schema from the exact binary under
test, update `manifest.toml`, run the runtime and provider contract suites, and
change `TESTED_CODEX_VERSION` in the same commit.
